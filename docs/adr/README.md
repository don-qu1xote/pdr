# Решения (ADR)

Здесь лежат решения, которые сняты с обсуждения. У каждого одна задача — не
дать вопросу всплывать каждые три месяца.

**ADR пишется до кода, а не как документация задним числом.** Решение,
записанное после того, как код написан, — это описание случившегося, а не
выбор; спорить с ним поздно, и никто не помнит, что рассматривали ещё.

## Формат

По файлу на решение, четыре раздела и статус:

```
# ADR-NNNN. Заголовок решения

**Статус:** Принято, ГГГГ-ММ-ДД.

## Контекст          чего мы не знали бы, если бы не записали
## Решение           что именно постановили
## Последствия       чем платим, включая неприятное
## Альтернативы и почему отвергнуты
```

**ADR без отвергнутой альтернативы — не решение, а описание.** Если ничего не
рассматривали, то и выбора не было; тогда запись бесполезна — через полгода она
не ответит на вопрос «а почему не так».

Статус меняется, но текст — нет: принятое решение не переписывают, его
**заменяют** новым, а старое получает статус «Заменено ADR-NNNN». История
решений — такая же история, как `git log`, и задним числом её не правят.
